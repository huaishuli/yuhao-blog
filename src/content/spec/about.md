# 关于 Huaishuli

你好，这里是 **Huaishuli**（怀姝离）的个人博客。

## ✨ 关于本站

这个站点用 **Astro** 构建，托管在 **Cloudflare Pages**，源码放在 [GitHub](https://github.com/huaishuli/yuhao-blog)，日常用 [Pages CMS](https://app.pagescms.org) 在浏览器里写文章，保存即提交、自动构建上线。

站点本身刻意保持简单：纯静态输出、没有服务端、没有数据库，搜索和评论也都由静态数据与第三方服务承担。这样它能在任何地方打开，也不会因为我哪天忘了续费服务器而消失。

## 📝 这里写什么

- **技术折腾**：Astro、Cloudflare、自建服务，以及各种踩过的坑
- **动漫与游戏**：在追的番、在玩的游戏、喜欢的画
- **日常碎念**：没有什么主题，只是记录
